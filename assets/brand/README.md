# Headcount repository artwork

`banner.png` is the 1600 x 560 README header. `avatar.png` is the 512 x 512
repository icon. Matching SVGs contain outlined lettering and can be rendered
without installing fonts. Alt text is supplied at each use.

The Studio brand pack owns the masters. `source.json` records the source
revision, exact selected files, and hashes. Regenerate through that owner and
refresh this explicit selection; retain later product edits for review.
SIL OFL font notices are included in `licenses/`.
